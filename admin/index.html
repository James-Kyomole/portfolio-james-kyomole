Cet écran filtre simplement les visiteurs occasionnels — ce n'est pas une vraie protection. La sécurité réelle vient de votre jeton d'accès personnel GitHub, que vous seul possédez et qui sera demandé à l'étape suivante.

Connexion à GitHub

Renseignez le dépôt GitHub qui héberge ce site et un jeton d'accès personnel (PAT) avec la permission Contents: Read and write sur ce seul dépôt. Le jeton n'est envoyé qu'à l'API GitHub — jamais stocké ailleurs que dans votre navigateur.

Les modifications sont écrites directement dans votre dépôt GitHub ; Vercel republie le site automatiquement en ~1 minute.
